## 데이터 수집 여부

앱이 데이터를 수집합니다: **예**

## 수집하는 데이터 유형 (App Store Connect 항목별)

### 연락처 정보 (Contact Info)
- **이메일 주소**: 수집함
  - 사용 목적: 앱 기능 (계정 생성 및 로그인), 사용자 ID
  - 타사 공유: 아니오
  - 추적 사용: 아니오

### 위치 (Location)
- **정확한 위치 (Precise Location)**: 수집함
  - 사용 목적: 앱 기능 (주변 음식점 추천)
  - 타사 공유: 아니오
  - 추적 사용: 아니오
  - 백그라운드 수집: 아니오 (포그라운드만)

### 식별자 (Identifiers)
- **사용자 ID**: 수집함 (익명 UUID)
  - 사용 목적: 앱 기능 (비로그인 사용자 서비스 제공)
  - 타사 공유: 아니오
  - 추적 사용: 아니오

### 사용 데이터 (Usage Data)
- **제품 상호 작용**: 수집함 (추천 이력, 즐겨찾기)
  - 사용 목적: 앱 기능 (기록 관리), 앱 기능 개선
  - 타사 공유: 아니오
  - 추적 사용: 아니오

### 광고 SDK (Google AdMob)가 수집하는 데이터
- **식별자 > 기기 ID(광고 식별자 IDFA)**: 수집함
  - 사용 목적: 제3자 광고
  - 추적 사용: **예** (이용자가 "추적 허용"을 선택한 경우에 한함)
- **사용 데이터 > 광고 데이터 / 제품 상호 작용(광고 노출·클릭)**: 수집함
  - 사용 목적: 제3자 광고
- **진단 (충돌 데이터 · 성능 데이터 등)**: 수집될 수 있음
  - 사용 목적: 분석

> **작성 시 주의**: 위 항목은 Google의 공식 안내
> "Google 모바일 광고 SDK의 Apple 개인정보 보호 세부 정보 가이드"에서 안내하는 항목을 요약한 것입니다.
> App Store Connect 입력 시 해당 가이드의 표와 대조해 빠진 항목(예: IP 기반 대략적 위치 등)이 없는지 확인하세요.

## 추적 여부

이 앱은 Google AdMob 광고를 위해 앱 최초 실행 시 Apple의 App Tracking Transparency(ATT) "추적 허용" 팝업을 표시합니다
(`NSUserTrackingUsageDescription` 문구 포함). 이용자가 허용하면 광고 식별자(IDFA)가 맞춤형 광고에 사용되므로
App Store Connect에서 **"추적에 사용되는 데이터"를 선언해야 합니다.** 이용자가 허용하지 않아도 앱은 동일하게 동작하며
광고는 비맞춤형으로 표시됩니다.

- **개인정보 삭제 요청**: 앱 내 문의하기 > 개인정보 문의

## App Store Connect 작성 시 참고 사항

App Store Connect > 앱 > App 개인정보 보호 섹션에서 위 내용을 바탕으로 작성합니다.

1. 개인 정보 처리 방침 URL 입력 (앱 내 제공됨을 명시)
2. 데이터 수집 여부: 예
3. 이메일 주소: 앱 기능 > 앱 기능 체크
4. 정확한 위치: 앱 기능 > 위치 공유 체크
5. 사용자 ID (익명): 앱 기능 > 분석 체크
6. 기기 ID(광고 식별자) / 광고 데이터 / 제품 상호 작용: 제3자 광고 체크, **추적에 사용됨 "예"**
7. 앱이 사용자 추적에 해당하므로 App Store Connect > 앱 개인정보 보호에서 추적 도메인·ATT 관련 답변을 광고 도입 사실에 맞게 수정
